# 🌐 Cairo SciVerse Teams

A dedicated workspace and team management system built for Science students at Cairo University. 

Cairo SciVerse Teams bridges the gap between different student committees by providing a centralized platform for categorizing tasks, managing team administration, and fostering sustainable collaboration.

## ✨ Core Features

* **Cross-Functional Workspaces:** Dedicated environments for Research, Media, Development, and other specialized teams.
* **Task Categorization & Tracking:** Streamlined assignment systems to keep projects organized and moving forward.
* **Leadership Administration:** Granular roles and permissions allowing team leaders to manage members, oversee progress, and distribute workloads effectively.
* **Sustainable Cooperation:** Built to preserve project history and documentation, ensuring smooth handoffs between student generations.

## 💻 Tech Stack
* **Frontend:** React, Next.js, Tailwind CSS
* **Database & Auth:** Supabase (PostgreSQL)
* **Deployment:** Vercel
